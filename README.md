# 💌 Особенное приглашение на свидание для Наты

Романтический интерактивный сайт-приглашение на пятничное онлайн-свидание с камерами, разработанный с акцентом на мобильные телефоны, тёплую световую палитру (без синего цвета), красивую анимацию и живое взаимодействие.

---

## ✨ Что включено на сайте:
1. **Интерактивный конверт**: при первом входе отображается конверт с восковой печатью «Для самой любимой Наты». При нажатии печать и конверт открываются с эффектом конфетти.
2. **Атмосферный музыкальный плеер**: деликатная романтическая lofi-мелодия на Web Audio API (звучит плавно, без необходимости скачивать mp3 или зависеть от сторонних серверов).
3. **Фоновые частицы на Canvas**: тёплые парящие искорки огня и полупрозрачные сердечки.
4. **Тексты признания и цитата Курта Кобейна**:
   - «Ты права насчет маленького количества романтики. Я тебя безумно люблю и считаю что отношения не должны угасать со временем.»
   - Стилизованный блок огня: «Лучше сгореть, чем угаснуть» — Курт Кобейн (Nirvana)
   - «И я с ним согласен. Я выберу сгореть от любви к тебе, чем дать ей угаснуть.»
   - «Я хочу сделать шаг и пригласить тебя на свидание. В эту пятницу, болтать с включенными камерами.»
5. **Динамический таймер**: обратный отсчет в реальном времени до пятничного вечера.
6. **Интерактивный чек-лист («При себе иметь»)**:
   - 1. Мою любимую девушку (тебя) ✨
   - 2. Вкусняшки, энергосики и чипсики 🥤🍟
   - 3. Хорошее настроение 🥰
   (Пункты отмечаются тапом, издают нежный звук и при закрытии всех 3 пунктов показывают победный бейдж).
7. **Кнопки ответа**:
   - «Я согласна! Буду ждать ❤️»: запускает праздничный салют конфетти и открывает **Билет на свидание**.
   - «Я подумаю... 😏»: забавная кнопка, которая уворачивается, шутит про чипсики и в итоге соглашается.
8. **Билет на свидание (VIP Pass)**:
   - Кнопка **«Добавить в календарь телефона»**: генерирует и скачивает файл `.ics` для Apple Calendar (iPhone) и Google Calendar.
   - Кнопка **«Написать мне»**: мгновенно открывает диалог с предзаполненным милым текстом согласия.

## 🚀 Как выложить на GitHub Pages за 1 минуту:

1. Создайте новый репозиторий на [GitHub](https://github.com/new) (например, `for-nata` или любое другое название).
2. Загрузите файлы `index.html`, `style.css` и `script.js` в корень репозитория:
   ```bash
   git init
   git add .
   git commit -m "Romantic date invitation for Nata"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```
   *(или просто перетащите файлы через браузер в репозиторий на GitHub)*.
3. В репозитории на GitHub перейдите во вкладку:
   **Settings** ➔ **Pages** (в левом меню)
4. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: выберите `main` (или `master`) и папку `/ (root)`
   - Нажмите **Save**.
5. Через 30–60 секунд появится ссылка вида:
   `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`
6. Отправьте эту ссылку Нате в Telegram или WhatsApp!
